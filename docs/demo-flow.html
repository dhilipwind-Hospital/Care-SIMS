Everyone signs in on the same /login page. It auto-detects staff, then platform, then doctor — so the doctor works there too even though she is a registry record rather than a staff account. The patient uses /patient/login and then picks the hospital.

Part 1 · Create and configure the hospital

01Register the organizationPlatform admin
  1. Organizations → Register Organization. Four steps: Organization Details → Location & Contact → Subscription & Features → Review & Register.
  2. Next stays disabled until a legal name is entered. Step 3 offers 52 feature toggles.
  3. Registering provisions one org-admin user, one location and 36 enabled features.

The org admin is created last inside the same request. Wait until the org's user list is non-empty before resetting demo passwords, or the admin keeps a random temporary one.

02Put a doctor on the registryPlatform admin
  1. Register the doctor, Verify them, Affiliate them to the organization and a location, then set a schedule.
  2. The registry lists doctors with VERIFIED / PENDING status and filter tabs for All · Pending · Verified · Rejected · Suspended.

The registry is global across every organization. Entries are archived rather than deleted, because prescriptions, lab orders, referrals and OT bookings reference the doctor by id.

03Locations, departments, staffadmin@simsbox.demo
  1. Locations — Sims Box runs two: Main Campus (where stock lives) and Branch Clinic.
  2. Departments — General Medicine, Pediatrics, Pharmacy, Laboratory, Emergency. A department needs only a name and code.
  3. Users & Staff → Add User — name, email, role, primary location and departments. Departments are what scope a nurse's triage queue.

Part 2 · The patient journey

04Register the patientReception
  1. Register Patient → demographics, then visit details: chief complaint, preferred doctor, department.
  2. Press ✓ Register Patient & Generate Token. This saves and queues in one action — the row shows Awaiting triage with a token number.

There is no separate send-to-triage step. The row's Triage button is greyed out with "Already in today's workflow".

05TriageNurse
  1. Triage lists patients waiting, filtered to the nurse's own departments.
  2. Pick an acuity: Emergency · Critical · Urgent · Semi-Urgent · Routine.
  3. Record vitals — BP Systolic and Diastolic are separate fields, plus Heart Rate, Temp, SpO₂, Respiratory Rate, Weight, Height, Pain.
  4. Complete Triage & Assign Doctor.

Acuity drives the queue: choosing Urgent flips the patient's queue token to URGENT so they sort ahead of earlier arrivals.

06ConsultationDoctor
  1. My Queue → patient → tabs Overview · SOAP Notes · Orders · History.
  2. Lab Order on the Orders tab: priority, test name, category, urgency, clinical notes → Place Lab Order.
  3. Refer beside the patient's name opens the referral form with them already selected — Internal or External, department or free-text facility, destination site, diagnosis, urgency.
  4. Write Prescription: pick each drug from the catalog and set dosage, frequency, route, days and Qty, then Send to Pharmacy.

Picking from the catalog is what lets the pharmacy match stock and price the line. Qty is required — without it the pharmacy has nothing to count out.

07LaboratoryLab technician
  1. The worklist names the ordering doctor on every row.
  2. ORDERED → Mark Collected → SAMPLE COLLECTED → Start Processing → IN PROGRESS → Enter Results → RESULTED → ✓ Validate → VALIDATED
  3. Enter Results opens a row per test: Result (required), Unit, Reference Range, Flag, Remarks → Submit Results.
  4. Once validated the row offers Print Report.
08Pharmacy — dispensePharmacist
  1. The queue shows the prescription number, prescribing doctor and a live stock badge per drug.
  2. Select the prescription, review medications and total, add Pharmacist Notes, then Dispense Medications.

The strongest thing to demo: stock is allocated first-expiry-first-out and really drops — dispensing 4 of a 200 batch leaves 196. Anything the pharmacy cannot account for comes back as a named shortfall rather than a false success. The pharmacist's note is appended to the doctor's, never overwriting it.

09Ward medication record — optionalNurse
  1. Medication Admin → Schedule Medication, search the admission, then pick from that patient's prescribed drugs.
  2. Drug, dose, route and frequency fill themselves and the dose is linked to the prescription it came from.

Dispensing deliberately does not auto-create these rows — choosing an administration time is the nurse's call.

10BillingBilling
  1. Consultation, lab and pharmacy charges have already rolled onto the patient's open visit invoice.
  2. Search by invoice number or patient name, open the invoice, Finalize, then Collect Payment.

Worth demonstrating: type more than the balance. It is refused with the exact outstanding figure, on the server as well as in the browser. The tiles are true tenant-wide figures — Collected Today means today.

11Patient portalPatient
  1. Sign in, Choose Your Hospital → Sims Box → Continue.
  2. Timeline shows the whole visit in order: appointment, triage, consultation, prescription, lab order, lab result, referral, invoice, payment, admission.
  3. Prescriptions filter by Dispensed; Lab Reports, Billing and Vitals History alongside.

Declined and cancelled referrals are withheld here on purpose — the portal shows a patient their care, not internal churn.

Before you present

Wake the backend first. It sleeps when idle and a cold start can exceed the app's own 30-second timeout, which looks exactly like a failed login. Load any page once and wait before you begin.
  • Skeletons, not empty tables. Grey placeholder bars are the loading state — give lists a moment.
  • Search boxes are debounced. Patient, drug, department and admission pickers fetch as you type; wait for the name before clicking.
  • Doctors order labs from the consultation, not the Lab Orders menu — that opens the laboratory's own processing screen.
  • Stock lives at Main Campus while the pharmacist's account sits at Branch Clinic. Stock figures are org-wide on purpose.
